# G-AI — Mobile Application

## 1. Overview
Cross-platform mobile client for iOS and Android:
- Portable workouts & Gym companion
- Mobile Camera-based Real-time Pose Detection & Audio Ducking (`UC-2.4`)
- Barcode Scanner for quick food nutrition logging (`UC-3.1`)
- Fasting & Hydration reminder push notifications (`UC-3.3`, `UC-6.2`)

## 2. Recommended Tech Stack
- **Option A**: React Native / Expo (Code-sharing with `apps/web` types & hooks)
- **Option B**: Flutter (Native performance, smooth 60 FPS animations)
